## Tujuan Website

Membuat portal informasi lowongan kerja (job portal) untuk alumni SMK Telkom Bandung. Website ini bersifat sebagai **media penyebaran informasi**, bukan platform rekrutmen penuh (bukan seperti Jobstreet). Proses apply/submission lamaran tetap dilakukan melalui platform/form milik perusahaan masing-masing.

---

## Fitur Utama

### 1. Portal Lowongan Kerja (Job Portal)
- Menampilkan info lowongan kerja dari mitra industri maupun perusahaan luar
- Lowongan tidak terbatas dari mitra SMK saja, bisa dari perusahaan lain yang relevan dengan jurusan alumni
- Jika perusahaan menyediakan form apply, website cukup menyematkan link-nya
- Info detail lowongan hanya bisa diakses setelah user membuat akun
- Konten akan di-update secara berkala oleh admin

### 2. Informasi Mitra Industri
- Menampilkan daftar mitra/industri yang sudah bekerja sama dengan SMK Telkom

### 3. Informasi PPDB
- Menampilkan info PPDB sekolah (bersifat seperti iklan/banner informasi)

---

## Jurusan yang Relevan

Lowongan yang ditampilkan disesuaikan dengan jurusan yang ada di SMK Telkom Bandung:

- **DKV** (Desain Komunikasi Visual)
- **Animasi**
- **TJKT** (Teknik Jaringan Komputer dan Telekomunikasi)
- **PPLG** (Pengembangan Perangkat Lunak dan Gim)

---

## Data Inputan Akun User

Saat registrasi, user diminta mengisi:

- Nama lengkap
- Email pribadi (email official sudah dinonaktifkan setelah lulus)
- No. HP
- Data pribadi lainnya
- Sudah pernah bekerja? *(Ya/Tidak)*
- Jika ya, bekerja di mana?
- Apakah kamu alumni SMK Telkom? *(Ya/Tidak)*

> **Catatan:** Email yang digunakan adalah email pribadi karena email official sudah dinonaktifkan setelah siswa lulus.

---

## Sisi User

- User hanya dapat melihat informasi lowongan (website bersifat informatif)
- Wajib membuat akun untuk melihat detail lengkap lowongan
- Tidak ada fitur apply langsung melalui website; diarahkan ke link perusahaan
- Website terbuka untuk umum, tidak hanya alumni

---

## Sisi Admin

- Upload/tambah lowongan kerja baru
- Manajemen konten lowongan (edit, hapus, update)
- Manajemen user (melihat data user)
- Reset password user dilakukan via email (tidak dikelola manual oleh admin)
- Validasi/moderasi data jika fitur crawling diaktifkan

---

## Fitur Tambahan: Crawling Lowongan (Usulan)

Fitur otomatis untuk mencari lowongan kerja dari luar dan memasukkannya ke website.

**Keputusan:** Boleh diterapkan, **dengan syarat:**

- Ada **proses penyaringan/validasi** oleh admin sebelum lowongan ditampilkan (tidak langsung 100% masuk)
- Data dipastikan **aman** — ada kekhawatiran soal keamanan data user jika website terlalu terbuka
- Pihak sekolah khawatir data alumni/user bisa diambil pihak yang tidak bertanggung jawab jika tidak ada filter yang memadai

---

## Keamanan

- Website perlu menjaga keamanan data user (khususnya alumni)
- Admin memiliki kontrol untuk menyetujui/menolak konten yang masuk
- Fitur reset password terhubung langsung ke email user
- Perlu ada lapisan keamanan agar data tidak mudah di-grab pihak luar
